Tab 切换储存标签 / Storage Tab Cycle 1.0.0

把本文件夹放入游戏根目录的 Mods 文件夹，在游戏 Mods 菜单启用并重启。
打开扩容储存区，点击窗口使其置前，按 Tab 切换下一标签，末页循环回第一页。
多个窗口时只处理最后置前的容器。输入文字、重绑快捷键、设置及暂停菜单时不触发。
无需前置 Mod。卸载时在 Mods 停用并重启即可。

Compiled against Steam build 26337366. Core tab cycling confirmed in game by the user on 2026-11-01.
本包已通过编译和游戏扫描器的离线检查；用户于 2026-11-01 确认游戏内核心切页功能可用，完整边界场景尚未逐项验收。
